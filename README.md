# Eye_Diagram
This is a diagram of the eye; it’s very helpful for studying the eye’s anatomy. You can use it to create simple examples to help understand which parts correspond to what.
# How this work
For now, in order for the program to work, you need to print out a 20-cm ArUco marker, which allows you to obtain distance data and calibrate the camera.
# IN THE FUTURE 
In the future, the marker will only be needed for camera calibration. We also plan to add a WebGUI, which will provide a better and more intuitive interface with easier editing.
